## VPN Connect v0.3.1

VPN Connect is an Android client for Sophos Firewall IPsec VPNs.

### Fixed in v0.3.1
- **Open WhatsApp** (Import › From WhatsApp) now opens WhatsApp or WhatsApp Business instead of saying it is not installed.
- **Browse WhatsApp Documents** now asks once for WhatsApp's documents folder, opening the folder picker right there, and from then on lists the `.scx` files WhatsApp has saved, newest first, ready to tap.

### Import from WhatsApp (since v0.3)
- **Share from WhatsApp:** in the chat, press and hold the `.scx` file, tap Share and choose VPN Connect. It is imported straight away, no folder hunting.
- **Open from WhatsApp:** tapping the `.scx` file in a chat offers VPN Connect.
- **Import menu:** "Import connection" (and the Import button) offers *Choose file…*, *From WhatsApp* (step-by-step help with an Open WhatsApp button) and *Browse WhatsApp Documents*.

### Everything else
- Import any Sophos Connect `.scx` file from the ⋮ menu (or open it from a file manager).
- The title line shows "VPN Connect" until a connection is imported, then the imported file's name.
- Connect with your user name and password; the Events tab lists connects, disconnects and failures.
- App ID `com.vpnconnect.app`. English.
- Author: zero.cyfa

### APK package
Download `VpnConnect-v0.3.1.apk` below, open it on the phone and allow "Install unknown apps" if asked. It installs over earlier versions and keeps your connections.
